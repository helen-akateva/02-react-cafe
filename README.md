# Cafe Feedback App

A simple and interactive cafe feedback application built with React and TypeScript. This project allows visitors to rate their cafe experience with good, neutral, or bad feedback, view statistics, and reset the votes.

## 🚀 Demo

[Live Demo](https://helen-akateva.github.io/cafe-feedback-app/)

## 📋 Description

This application demonstrates a feedback collection system for a cafe. Users can:
- Vote for their experience (Good, Neutral, or Bad)
- View real-time statistics of collected feedback
- See the percentage of positive feedback
- Reset all votes to start fresh

The app showcases React state management, TypeScript integration, and component-based architecture with a clean, modular structure.

## 🛠️ Technologies

- **React** 19.1.1 - UI library

- **Vite** (Rolldown) - Fast build tool and development server

- **Modern Normalize** - CSS reset for consistent styling across browsers

## ✨ Features

- Interactive voting interface with three feedback options
- Real-time statistics display
- Positive feedback rate calculation
- Reset functionality to clear all votes
- Responsive and clean user interface
- TypeScript for type safety
- Component-based architecture
- Modern React hooks (useState)

## 📦 Installation

1. Clone the repository:
```bash
git clone https://github.com/helen-akateva/cafe-feedback-app.git
cd cafe-feedback-app
```

2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm run dev
```

4. Open your browser and navigate to `http://localhost:5173`

## 🏗️ Available Scripts

- `npm run dev` - Start development server
- `npm run build` - Build for production
- `npm run preview` - Preview production build
- `npm run lint` - Run ESLint
